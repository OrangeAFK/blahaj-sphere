# scripts/legacy

One-off milestone scripts (M2.5-M7) kept for reference only: they predate the tracks layout (M7.5) and the learner/builder container split (M7.6) and are **not maintained** (stale signatures and paths, several are live and spend subscription quota). Run them as `uv run python -m scripts.legacy.<name>`, expect to fix them first, and never point them at the real `data/`; current acceptance scripts (`m75_acceptance.py`, `tempdata.py`) stay in `scripts/`.
